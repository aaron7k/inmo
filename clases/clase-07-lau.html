🔗 Conectar Claude a Meta para alertas,
optimizaciones y A/B testing

Automatiza tu stack de paid media con la Meta Marketing API y Claude

Presentadora: Lau Viernes 26 junio 2026 90 minutos Paid media
🎯 Objetivos de la clase
  • 1 Conectar Claude con la Meta Ads API usando el MCP oficial de Meta o conectores como Make.com, Zapier y n8n, sin exponer credenciales ni arriesgar la cuenta publicitaria.
  • 2 Crear alertas automáticas de rendimiento que notifiquen por Slack o WhatsApp cuando el CPA, CPM o ROAS se salgan del rango objetivo.
  • 3 Automatizar el ciclo completo de A/B testing: generación de variantes → lanzamiento → monitoreo → pausa del perdedor → escalado del ganador.
  • 4 Implementar un bucle de optimización continua donde Claude analiza resultados, propone cambios y los ejecuta a través de la API con supervisión humana mínima.
🔑 Conceptos clave

API (Application Programming Interface)

Conjunto de endpoints que Meta expone para leer y escribir datos de campañas sin entrar al Ads Manager. La Meta Marketing API (rama de la Graph API v21+) es la que usamos en esta clase.

MCP — Model Context Protocol

Estándar abierto de Anthropic que permite a Claude comunicarse con servicios externos de forma segura. Meta lanzó su Meta Ads MCP Server en open beta (abril 2026): da a Claude acceso autenticado a 29 herramientas que cubren toda la Marketing API, sin generar tokens manualmente.

Webhooks

Notificaciones HTTP que Meta (o Make/n8n) envía a tu sistema cuando ocurre un evento: gasto supera umbral, un ad cae a delivery limitado, ROAS baja del objetivo. Claude recibe el payload y decide la acción.

Alertas de rendimiento

Reglas que disparan un mensaje automático cuando una métrica clave cruza un umbral. Ejemplos: CPA > objetivo × 1.2, frecuencia > 4, CTR < 0.8 %. La alerta puede ir a Slack, WhatsApp Business o email.

A/B testing con IA

Proceso donde Claude genera variantes de copy/creatividad, las lanza como split test vía API, monitorea estadísticamente cuál gana, pausa los perdedores y escala el presupuesto del ganador de forma automática.

Automatización de flujos (Make / Zapier / n8n)

Plataformas de orquestación que actúan de pegamento entre la Meta Ads API, Claude y el resto del stack (Sheets, Slack, CRM). Permiten construir flujos visuales sin código profundo.

03 A/B testing automatizado 25 min

El ciclo completo orquestado por Claude: de la generación de variantes al escalado del ganador.

Briefing → Claude genera variantes → API crea ads → Split test Meta → Claude monitorea → Pausa perdedor → Escala ganador
Prompt para generar variantes de copy
Crea 4 variantes de copy para un anuncio de Facebook/Instagram. Producto: {{producto}} | Público: {{audiencia}} Oferta: {{oferta}} | Tono de marca: {{tono}} Para cada variante genera: - Titular (máx 40 caracteres) - Texto principal (máx 125 caracteres) - CTA sugerido Cada variante prueba un ángulo diferente: A) Beneficio principal B) Urgencia / escasez C) Prueba social D) Pregunta / curiosidad

Reglas de pausa automática: Si CPA > objetivo × 1.5 tras gastar 50 € → pausar. Si CTR < promedio × 0.6 → pausar. Al llegar al 95 % de significancia estadística → declarar ganador y registrar aprendizajes en Sheets.

💪 Ejercicio práctico

La alerta del CPA — Flujo en Make.com

Crea un flujo que detecte cuándo el CPA sube más del 20 % respecto al objetivo y envíe un análisis de Claude a Slack.

  1. Crear cuenta en Make.com (gratis) y conectar tu cuenta de Meta Ads mediante OAuth
  2. Nuevo escenario → Scheduled trigger cada día a las 9 am
  3. Módulo Meta Ads → Get Ad Insights (últimas 24 h): métricas spend, actions, cost_per_action
  4. Módulo Tools → Set variable: calcular cpa_actual = spend / conversiones
  5. Router: condición cpa_actual > cpa_objetivo * 1.20 — Rama SÍ continúa, Rama NO termina
  6. Módulo Anthropic Claude: enviar el prompt de análisis con los datos reales de Meta
  7. Módulo Slack: enviar mensaje al canal #alertas-paid con el output de Claude
