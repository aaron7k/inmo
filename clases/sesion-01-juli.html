🔑 Conceptos clave
TérminoDefinición
System Prompt Instrucción de configuración que se da a la IA antes de la conversación, definiendo su rol, expertise, tono y restricciones. Es la forma más rápida y económica de "entrenar" una IA para investigación.
RAG Retrieval-Augmented Generation. La IA busca en una base de datos propia (tus papers, notas, documentos) antes de responder. Logra 94–98% de precisión en preguntas de dominio específico.
Fine-Tuning Reentrenamiento del modelo con datos propios. Costoso (+5.000 USD de inversión inicial), lento de iterar y frecuentemente sobre-aplicado. Solo vale cuando se necesita comportamiento muy específico a gran escala.
Context Window Texto que la IA puede procesar en una conversación. Claude maneja 200K tokens (~15 papers completos). NotebookLM ahora soporta 1 millón de tokens con el motor Gemini 3.
NotebookLM Herramienta de Google que analiza hasta 50 fuentes (PDFs, URLs, YouTube, audio) y responde con citas ancladas en tus documentos. Ideal para research libre de alucinaciones.
Claude Projects Espacio de trabajo persistente en Claude donde cargas papers base, notas metodológicas y configuras skills. Se convierte en un laboratorio de investigación completo y reutilizable.
Perplexity Deep Research Realiza docenas de búsquedas automáticas y lee cientos de fuentes, entregando reportes comprehensivos con citas verificables en 2–4 minutos.
Elicit Asistente científico con acceso a 125M papers. Extrae datos estructurados, soporta PRISMA 2020 y logra 95% de recall en revisiones sistemáticas. Más de 2 millones de investigadores lo usan.
Consensus Motor académico que sintetiza evidencia de estudios revisados por pares y muestra el nivel de acuerdo científico sobre una pregunta concreta.
Prompt XML estructurado Uso de etiquetas XML (<rol>, <contexto>, <tarea>, <restricciones>) que Claude parsea como input estructurado, mejorando significativamente la precisión del análisis académico.
Zotero Gestor de referencias gratuito y open-source. Soporta 9.000+ estilos de cita, integra con Word, Google Docs y Overleaf. Captura referencias directamente desde el navegador.
Fuentes primarias Papers originales, datos crudos, reportes directos. La IA debe siempre anclarse a ellas — nunca generarlas. NotebookLM + Elicit son los guardianes de este principio.
⚖️ Framework: ¿qué enfoque usar?

La pregunta más frecuente: ¿cuándo usar system prompts, RAG o fine-tuning? La respuesta depende de tu caso de uso.

Enfoque Cuándo usarlo Costo / Velocidad Precisión
System Prompt Base de conocimiento <200K tokens. Necesitas velocidad y flexibilidad. Quieres iterar rápido. Horas de setup · Gratis Alta si el prompt es bien estructurado
RAG Biblioteca de documentos propia (papers, notas, datos). Necesitas información actualizada. Quieres citas verificables. Días de setup · Bajo costo 94–98% en dominio específico
Fine-Tuning El modelo debe aprender comportamiento o estilo muy específico. Escala de producción (miles de queries diarios). Semanas · +5.000 USD Máxima — pero solo si los datos son buenos
Híbrido RAG + FT Los sistemas de producción más avanzados de 2026. RAG para hechos, fine-tuning para comportamiento y razonamiento. Meses · Empresa Estado del arte

Para investigación individual: system prompts + RAG (NotebookLM) es la combinación óptima en 2026. Fine-tuning raramente se justifica.

💪 Ejercicio personalizado: asistente de investigación propio

Durante la sesión construiremos en vivo un asistente de investigación con system prompt específico para el área de Juli. El resultado es una plantilla lista para usar desde el primer día.

Plantilla de System Prompt base (a personalizar en sesión)
<rol> Eres un asistente de investigación experto en [ÁREA ESPECÍFICA DE JULI]. Tienes experiencia en metodología [CUANTITATIVA / CUALITATIVA / MIXTA]. Conoces los principales journals, metodologías y debates actuales del campo. </rol> <comportamiento> - Siempre cita fuentes específicas. Si no tienes certeza, dilo explícitamente. - Usa lenguaje académico riguroso pero claro. - Cuando analices papers, extrae: objetivo, metodología, muestra, hallazgos clave y limitaciones. - Si encuentras contradicciones entre fuentes, señálalas y explica el debate. - Nunca inventes datos, estadísticas o referencias bibliográficas. </comportamiento> <formato_de_respuesta> Para síntesis de literatura: usa estructura IMRAD adaptada. Para comparación de estudios: tabla con columnas: Autor/Año | Muestra | Metodología | Hallazgo principal | Limitación. Para brechas de investigación: lista numerada con nivel de evidencia. </formato_de_respuesta> <restricciones> - Solo trabaja con información que yo te proporcione o puedas verificar. - Si la pregunta está fuera de mi área, indícalo y sugiere alternativas. - Longitud: concisa por defecto, extensa solo si lo solicito explícitamente. </restricciones>
