Al finalizar esta asesoría, Norma será capaz de:

## 🔑 Conceptos clave

### Automatización contable con IA
La IA aplica aprendizaje automático para ejecutar tareas contables repetitivas: categorización de transacciones, creación de asientos de ajuste, detección de anomalías y generación de reportes. Las plataformas modernas combinan automatización con revisión humana para garantizar precisión.

### Análisis de varianzas
Proceso de comparar resultados reales contra presupuesto o período anterior. Claude puede identificar varianzas significativas (>10%), realizar análisis de causa raíz, distinguir factores temporales de permanentes y generar recomendaciones de acción priorizadas para la dirección.

### Conciliación bancaria con IA
Automatización del proceso de cruce entre registros contables y estados de cuenta bancarios. Los sistemas con IA reducen el tiempo de conciliación de 47 minutos (proceso manual) a 10-20 minutos, y bajan la tasa de errores del 4.2% al 0.3%.

### IVA e impuestos con IA
Uso de modelos de lenguaje como Claude para revisar declaraciones de IVA, detectar ingresos o deducciones mal clasificados, calcular diferencias y preparar resúmenes ejecutivos para el contador o el auditor. También sirve para automatizar el llenado de formatos fiscales con datos estructurados.

### Captura inteligente de documentos
Tecnología OCR + IA que extrae automáticamente datos de facturas, recibos y estados de cuenta con precisión de hasta 99.9%, sincronizando los datos directamente al software contable (Dext Prepare, QuickBooks, Xero).

### Prompts contables efectivos
Instrucciones precisas para que la IA ejecute tareas específicas: analizar un estado de resultados, detectar gastos inusuales, comparar períodos, o redactar un memo para la dirección. La calidad del prompt determina la calidad del análisis.

## 💪 Ejercicio práctico

### "Auditoría rápida con Claude"

**Objetivo:** Analizar un estado de resultados real (o ficticio) con Claude e identificar anomalías, varianzas y puntos de atención para la dirección.

**Paso a paso:**

1. **Preparar los datos** — Tomar el estado de resultados del último trimestre (o usar el ejemplo proporcionado en sesión). Puede ser en texto pegado directamente o subido como archivo PDF/Excel a Claude.

2. **Usar este prompt base:**
   ```
   Eres un contador experto. Analiza el siguiente estado de resultados y:
   1. Identifica todas las varianzas significativas (>10% vs período anterior)
   2. Detecta gastos o ingresos que parezcan inusuales o fuera de rango
   3. Realiza un análisis de causa raíz para las 3 varianzas más importantes
   4. Indica cuáles son temporales y cuáles pueden ser permanentes
   5. Redacta un resumen ejecutivo de 5 puntos para presentar a la dirección
   
   Estado de resultados:
   [PEGAR DATOS AQUÍ]
   ```

3. **Revisar el output** — Verificar que las varianzas identificadas correspondan con la realidad del negocio. La IA puede cometer errores de contexto; la revisión humana sigue siendo esencial.

4. **Iterar** — Hacer preguntas de seguimiento: "¿Qué pasaría si los gastos de nómina aumentan 15% el próximo trimestre?" o "¿Cómo se compara este margen bruto con el promedio del sector?"

5. **Exportar** — Copiar el análisis a un documento Word o Google Docs para incluirlo en el reporte mensual.

**Resultado esperado:** Análisis de varianzas completo + narrativa ejecutiva en menos de 5 minutos, vs. 60-90 minutos de forma manual.
