🔑 Conceptos Clave

Model Context Protocol (MCP)

Estándar abierto de Anthropic (nov. 2024) basado en JSON-RPC 2.0. Conecta Claude con herramientas externas de forma bidireccional y segura. El "USB universal" de la IA. Adoptado por OpenAI, Google y Microsoft.

API (REST)

Interfaz que permite a programas externos comunicarse con Claude mediante código. Base de todas las integraciones avanzadas. Endpoint: api.anthropic.com/v1/messages.

Extensión de Navegador

Programa instalado en Chrome/Edge/Brave que añade Claude directamente a la experiencia de navegación. Claude puede ver páginas, hacer clic y rellenar formularios.

Automatización No-Code

Plataformas visuales (Zapier, Make.com, n8n) que permiten conectar Claude con cientos de apps mediante flujos gráficos, sin programar. Claude actúa como motor de inteligencia.

Claude Cowork

Funcionalidad de Claude Desktop que ejecuta tareas agenticas en una VM local aislada. Accede a archivos locales y conectores MCP para trabajo de conocimiento más allá del código.

Servidor MCP

Servicio que expone herramientas y recursos a Claude mediante el protocolo MCP. Hay más de 10,000 servidores públicos en 2026: GitHub, Slack, Notion, Postgres, Filesystem...

📋 Contenido — 4 Módulos
01 Panorama General — El Ecosistema de Extensiones Claude 20 min

Claude.ai en el navegador es poderoso, pero su verdadero potencial se libera cuando se conecta con el contexto de tu trabajo real: tus archivos, tu código, tus emails, tu calendario. Las extensiones e integraciones eliminan el copiar-y-pegar constante y convierten a Claude en un colega digital que ya conoce tu entorno.

Las 5 capas del ecosistema Claude (2026):

1
Apps nativas — Claude Desktop + Claude.ai web. Base de todo el ecosistema.
2
Extensiones de interfaz — Navegador (Chrome) e IDE (VS Code, JetBrains). Claude trabaja donde tú trabajas.
3
Integraciones MCP — Conexiones directas y bidireccionales con servicios externos. Claude lee y escribe en tus herramientas.
4
Automatizaciones — Zapier / Make.com / n8n. Flujos que se ejecutan solos; Claude como motor de inteligencia.
5
Infraestructura empresarial — API directa, Amazon Bedrock, Google Vertex AI. Para integraciones a escala.
02 Extensiones de Navegador — Claude en Chrome 20 min

Claude en Chrome es la extensión oficial de Anthropic para todos los navegadores basados en Chromium. Llegó como preview en agosto 2025 (1,000 testers), se expandió a suscriptores Max en noviembre 2025, y desde diciembre 2025 está disponible en beta para todos los planes pagos.

⚠️ Consideración de seguridad Riesgo de prompt injection: actores maliciosos pueden intentar inyectar instrucciones en páginas web para engañar a Claude. Siempre revisa las acciones propuestas antes de autorizar operaciones sensibles.

Capacidades principales:

  • Se ejecuta en el panel lateral — Claude ve lo que tú ves en tiempo real
  • Puede hacer clic, navegar páginas y rellenar formularios en tu nombre
  • Aprende flujos de trabajo: graba los pasos, Claude los repite automáticamente
  • Se integra con Claude Code para flujos web → código → deploy
  • Comparte el estado de login del navegador; accede a sitios en los que ya estás autenticado
💡 Modelos por plan Plan Pro ($20/mes) → Haiku 4.5 (más rápido). Plan Max ($100-200/mes) → Sonnet y Opus completos con más capacidad.
03 Integraciones No-Code — Zapier, Make.com y n8n 25 min

Las plataformas de automatización permiten conectar Claude con cualquier aplicación sin escribir código. Claude aporta el "cerebro" (comprensión, redacción, clasificación) y la plataforma aporta la "fontanería" (cuándo disparar el flujo, adónde enviar los resultados).

⚡ Zapier

+9,000 apps integradas. El más accesible para equipos no técnicos. MCP support desde abril 2025 (30,000+ acciones en una sesión agentica). Acción principal: "Create Conversation" — Claude procesa y genera respuesta.

Free / desde $19.99/mes

🔧 Make.com

Constructor visual drag-and-drop con nodos, bifurcaciones y bucles. Ideal para flujos complejos con condicionales y transformación de datos. Integración nativa con la API de Anthropic.

Free / desde $9/mes

🛠️ n8n

Open source y self-hosteable. Para equipos técnicos con control de costos. Claude como capa de inteligencia dentro de flujos complejos. Batch API: 50% de descuento para volúmenes altos.

Self-hosted gratis / cloud $20+/mes

Ejemplos de flujos automatizados:

  • Nuevo email → Claude resume y clasifica → guardado en Notion automáticamente
  • Nuevo lead en CRM → Claude redacta email personalizado → enviado al instante
  • Artículo RSS → Claude traduce y adapta → publicado en Slack del equipo
  • PDF de cliente → Claude extrae datos estructurados → hoja de cálculo actualizada
  • Formulario de contacto → Claude clasifica prioridad → ticket creado en Jira
📌 Stack recomendado para equipos n8n como motor central + Claude Code para proyectos de código + Zapier/Make para automatizaciones rápidas ad-hoc.
04 MCP Avanzado — Conecta Claude con Todo 25 min

MCP es el estándar de integración más importante del ecosistema IA 2024-2026. A diferencia de las APIs tradicionales (unidireccionales), MCP crea un canal persistente donde Claude puede leer y escribir en tus herramientas.

10,000+
Servidores MCP activos (2026)
97M
Descargas mensuales del SDK
50+
Conectores 1-clic en Claude.ai
Nov 2024
Lanzamiento por Anthropic

Arquitectura de tres capas:

[HOST] Claude Desktop / VS Code / Claude.ai
        ↓
[CLIENT] Puente MCP interno (dentro del host)
        ↓
[SERVER] Servicio externo con sus herramientas
        ↓
[RECURSO] GitHub API / Base de datos / Archivos

Servidores MCP oficiales de Anthropic:

GitHub

Leer repos, crear PRs, revisar código, gestionar issues

Slack

Enviar mensajes, leer historial de canales, buscar usuarios

Google Drive

Buscar, leer y crear archivos en Drive

Notion

Leer y escribir páginas, bases de datos y comentarios en tiempo real

PostgreSQL

Ejecutar consultas SQL, leer esquemas de base de datos

Filesystem

Acceder a archivos y carpetas del sistema local

Git

Operaciones de control de versiones en repos locales

Jira

Crear y gestionar tickets, sprints y proyectos

Puppeteer

Control de navegador headless para automatización web

Zapier MCP

Acceso a 30,000+ acciones de las 9,000 apps de Zapier

Configuración en Claude Desktop (ejemplo):

{ "mcpServers": { "github": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-github"], "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "tu-token" } }, "filesystem": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem", "/ruta/carpeta"] } } }

Gobernanza y adopción: Desde diciembre 2025, MCP está administrado por la Linux Foundation bajo el Agentic AI Foundation (AAIF), co-fundado por Anthropic, OpenAI y Block. OpenAI lo adoptó en marzo 2025; Google DeepMind y Microsoft Copilot Studio también lo integran.

💪 Ejercicio Práctico
🅐 Parte A — Claude Code en VS Code (15 min)
  1. Verificar versión de VS Code: debe ser 1.98.0 o superior (Ayuda → Acerca de)
  2. Abrir Extensions: Ctrl+Shift+X (Win/Linux) o Cmd+Shift+X (Mac)
  3. Buscar "Claude Code" (publicador: Anthropic) → clic en Instalar
  4. Abrir cualquier archivo de código → aparece el icono ✦ en la esquina superior del editor
  5. Clic en ✦ → hacer clic en Sign in → autorizar en el navegador
  6. Seleccionar un bloque de código y preguntar: "Explica qué hace esta función"
  7. Pedir: "Encuentra los bugs en este archivo y corrígelos" → revisar el diff antes de aceptar
🅑 Parte B — Flujo Automatizado en Zapier (15 min)

Flujo: Nuevo formulario de contacto → Claude clasifica y resume → Guardado en Google Sheets

  1. Crear cuenta gratuita en zapier.com → clic en "Create Zap"
  2. Trigger: "Webhooks by Zapier" → "Catch Hook" (o usa Google Forms si lo tienes)
  3. Agregar acción: buscar "Anthropic (Claude)" → "Create Conversation"
  4. Conectar cuenta con API key de console.anthropic.com
  5. Escribir el prompt con las variables del formulario (nombre, mensaje, empresa)
  6. Seleccionar modelo: Claude 3.5 Sonnet → probar la acción
  7. Agregar acción final: "Google Sheets" → "Create Row" → mapear campos de Claude
  8. Activar el Zap → enviar datos de prueba → verificar resultado en Sheets
Prompt de ejemplo: Analiza este mensaje de un cliente y responde en JSON: - resumen: qué necesita (1 oración) - prioridad: Alta / Media / Baja - siguiente_paso: acción recomendada Nombre: {{nombre}} | Empresa: {{empresa}} Mensaje: {{mensaje}}
⭐ Bonus — Conectar servidor MCP (para quienes terminen antes)
  1. Descargar Claude Desktop desde claude.com/download
  2. Editar el archivo de configuración MCP (ver Módulo 4 para la estructura JSON)
  3. Agregar el servidor de Filesystem apuntando a tu carpeta de Documentos
  4. Reiniciar Claude Desktop → pedir: "Lista todos los archivos .pdf en mi carpeta Documentos"
