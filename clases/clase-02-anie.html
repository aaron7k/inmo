🔑 Conceptos clave

Anatomía del prompt: los 5 componentes

Componente Descripción Ejemplo práctico
Rol Define quién es la IA para esta tarea. Proporciona perspectiva, voz y expertise. "Actúa como un agente inmobiliario con 15 años de experiencia..."
Contexto Información de fondo que el modelo necesita para entender la situación única. "...estoy lanzando una app para el mercado latinoamericano..."
Instrucción La tarea concreta, directa y sin ambigüedad. El "qué hacer". "...escribe 3 variantes de asunto para un correo de bienvenida."
Ejemplos Muestras del output esperado (few-shot). Anclan tono y formato. "Ejemplo: 'Bienvenido a tu nuevo hogar digital'"
Formato de salida Especifica el tipo de respuesta: lista, tabla, párrafo, JSON, etc. "Devuelve una lista numerada, máximo 10 palabras por ítem."

Técnicas de prompting

Zero-shot

Sin ejemplos previos. El modelo responde solo con su conocimiento preentrenado. Ideal para tareas simples y directas.

One-shot

Un solo ejemplo antes de la tarea. Útil para establecer el tono o formato deseado rápidamente.

Few-shot

3–5 ejemplos incluidos en el prompt. Aumenta la consistencia del output para tareas complejas o específicas.

Chain-of-Thought

Se pide al modelo razonar paso a paso. Se activa con: "Piensa paso a paso". Ideal para análisis y toma de decisiones.

Role prompting

Asignar un rol experto al modelo para obtener respuestas con perspectiva especializada y tono adecuado.

El principio central: la calidad del output es directamente proporcional a la calidad del input. Un prompt vago produce una respuesta vaga. Un prompt específico produce una respuesta específica.

Errores comunes que debes evitar

  • Instrucciones ambiguas: "hazlo mejor", "algo creativo", "lo que creas conveniente"
  • Ausencia de contexto: el modelo no sabe para quién, por qué ni en qué situación
  • Sin especificación de formato: la IA elige uno por defecto que puede no ser útil
  • Prompts sin estructura en bloques de texto muy largos
  • No iterar: aceptar el primer resultado como definitivo sin refinar

📋 Contenido por módulos
Módulo 1 — Qué es el prompt engineering
0 – 20 min

El prompt engineering es el puente entre la intención humana y el output de la IA: la práctica de traducir objetivos en instrucciones precisas que el modelo puede interpretar con exactitud. Ha evolucionado de ser una curiosidad a convertirse en una habilidad profesional estratégica.

  • Definición y relevancia actual: en 2025 se catalogaron más de 58 técnicas de prompting
  • El mismo modelo + prompts distintos = resultados radicalmente diferentes
  • Demo en vivo: comparación de un prompt vago vs. un prompt estructurado en Claude.ai
  • Por qué los prompts son ahora la capa de control de toda aplicación con LLMs
Módulo 2 — Anatomía del prompt: los 5 componentes
20 – 45 min

Desglose profundo de cada elemento que compone un prompt de alta calidad. Aprenderemos a tratarlo como un contrato: definir qué queremos, qué información puede usar el modelo, qué restricciones aplican y el formato exacto del output.

  • Rol, Contexto, Instrucción, Ejemplos, Formato — análisis con casos reales
  • Uso de etiquetas y separadores para estructurar prompts complejos
  • Cuándo incluir ejemplos y cuántos usar (3–5 para resultados óptimos)
  • Ejercicio guiado: construir un prompt completo desde cero para un caso del equipo
Módulo 3 — Técnicas de prompting
45 – 65 min

Exploración práctica de las técnicas fundamentales: cuándo usarlas, cómo activarlas y qué diferencia produce cada una en el output.

  • Zero-shot: casos ideales y limitaciones
  • Few-shot: cómo incluir ejemplos para anclar tono y formato
  • Chain-of-Thought: "Piensa paso a paso" para razonamiento complejo
  • Role prompting: asignar personas expertas al modelo
  • Comparativa en vivo: la misma tarea con las 4 técnicas
Módulo 4 — Iteración y mejora continua
65 – 90 min

El prompting efectivo no es un acto único, es un proceso. Aprenderemos a evaluar outputs, identificar puntos de mejora y ajustar con precisión quirúrgica.

  • El ciclo de iteración: evaluar → identificar → ajustar → repetir
  • Ajustes de tono, longitud, restricciones y especificidad
  • Prompts como documentos vivos: guardar, versionar y reutilizar los mejores
  • Adaptive prompting: sistemas que se auto-optimizan con feedback
  • Cierre: ejercicio final + Q&A
💪 Ejercicio práctico: Reescritura de prompts

Transforma prompts vagos en prompts claros y completos aplicando la anatomía de los 5 componentes. Prueba ambas versiones en Claude.ai o ChatGPT y compara los resultados.

Instrucciones:

  1. Observa el prompt original (vago)
  2. Identifica qué componentes faltan: rol, contexto, instrucción, ejemplos, formato
  3. Reescribe el prompt incorporando todos los elementos
  4. Prueba ambas versiones en tu herramienta de IA preferida
  5. Compara los outputs y discute en equipo: ¿qué cambió? ¿qué mejoró?

Caso A — Bienes raíces: descripción de propiedad

Prompt original (vago)
"Escribe algo sobre una propiedad."
Prompt mejorado (estructurado)
"Actúa como un agente inmobiliario experto en propiedades de lujo en Ciudad de México. Tengo una casa en Polanco de 350 m², 4 recámaras, alberca y jardín, precio: $8,500,000 MXN. Escribe una descripción de venta para portal inmobiliario de máximo 120 palabras, en tono profesional pero cercano, destacando los 3 beneficios principales. Formato: un párrafo continuo, sin bullet points."

Caso B — Atención a clientes: correo a cliente frustrado

Prompt original (vago)
"Responde al cliente enojado."
Prompt mejorado (estructurado)
"Eres un especialista en atención al cliente de una empresa inmobiliaria. El cliente Juan García dice que lleva 3 semanas sin recibir actualizaciones sobre su trámite de escrituración. Está frustrado y considera cancelar. Escribe un correo de respuesta empático que reconozca la espera, explique los próximos pasos concretos con fechas aproximadas, y ofrezca una llamada de seguimiento. Tono: profesional y cálido. Extensión: máximo 150 palabras."

Caso C — Redes sociales: post de Instagram

Prompt original (vago)
"Haz un post de Instagram."
Prompt mejorado (estructurado)
"Actúa como community manager especializado en real estate. Crea un post de Instagram para anunciar una nueva propiedad: departamento de 2 recámaras en Guadalajara, zona Zapopan, $2,800,000 MXN. Audiencia: parejas jóvenes de 28–40 años. Incluye: gancho inicial impactante, 3 beneficios clave como bullet points, llamada a la acción y 5 hashtags relevantes. Tono: aspiracional y accesible."

Reflexión grupal

  • ¿Cuánto tiempo tardaste en mejorar el prompt?
  • ¿Cuál fue la diferencia de calidad en el output?
  • ¿Qué elemento (rol, contexto, formato...) tuvo mayor impacto en el resultado?
